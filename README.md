# Портфолио на HTML, CSS и Bootstrap 5

Персональный одностраничный сайт-портфолио: биография, навыки, проекты и
контакты. Без сборки и зависимостей — HTML и CSS, готовые к
публикации на GitHub Pages.

## Что внутри

- **Bootstrap 5.3.3** — сетка, компоненты, утилиты.
- **Два режима оформления** — светлый и тёмный, на одной палитре Bootswatch Flatly.
  CSS-переключатель позволяет выбрать тему; без выбора применяется настройка
  системы (`prefers-color-scheme`). Выбранная тема не сохраняется после перезагрузки.
- Одинаковый системный шрифт в обоих режимах, работает без внешних запросов к шрифтам.
- Адаптивная вёрстка, CSS-мобильное меню, плавные появления секций, поддержка
  `prefers-reduced-motion`, семантика и ARIA-атрибуты.
- Иконки Bootstrap Icons встроены спрайтом — шрифты не нужны.
- Исполняемый JavaScript не используется. JSON-LD в конце HTML — только структурированные данные.

```
index.html                     страница целиком (все разделы + спрайт иконок)
.nojekyll                      отключает обработку Jekyll на GitHub Pages
assets/
  css/theme.css                оформление, темы и мобильное меню
  img/photo-placeholder.svg    заглушка вместо фото (4:5)
  img/favicon.svg              иконка сайта
  vendor/themes/flatly.min.css одна палитра Bootswatch (локально)
```

## Как заменить данные на свои

Все заглушки помечены комментариями `TODO:` в `index.html`.

1. **ФИО** — `<title>`, `<h1>`, `navbar-brand`, футер и JSON-LD в конце файла.
2. **Фото** — положите снимок в пропорции 4:5 (например `assets/img/photo.jpg`)
   и замените `src` у `<img class="...">` в секции `#home`. Рекомендуемый
   размер — 800 × 1000 px. Не забудьте обновить `alt`.
3. **Вуз** — секция `#bio`, карточка «Где учусь» и бейдж в hero.
4. **Интересы и увлечения** — карточки в `#bio`.
5. **Навыки** — секция `#skills`: перечислите только актуальные технологии и темы.
6. **Проекты** — секция `#projects`: заголовок и описание каждого проекта.
7. **Контакты** — футер страницы и hero: `mailto:`, Telegram, GitHub.
8. **GitHub-ссылки** — замените ссылки на профиль и репозитории, если они изменятся.
9. **Соцпревью** — укажите абсолютный URL картинки в `og:image`.
10. **Метаданные** — `description`, `author`, JSON-LD `Person`.

## Локальный просмотр

Сайт работает и при открытии `index.html` двойным кликом. Чтобы проверить
поведение как на хостинге, запустите простой сервер из папки проекта:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий **`<ваш-username>.github.io`** (именно так сайт
   откроется по корню домена).
2. В папке проекта выполните:

   ```bash
   git add .
   git commit -m "Портфолио на Bootstrap"
   git branch -M main
   git remote add origin https://github.com/<ваш-username>/<ваш-username>.github.io.git
   git push -u origin main
   ```

3. В GitHub откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Deploy from a branch**,
   ветку `main` и папку **/ (root)**. Сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-username>.github.io/`.

Если используете обычный репозиторий (не `<username>.github.io`), сайт
откроется по адресу `https://<ваш-username>.github.io/<repo>/`. Все пути в
проекте относительные, поэтому дополнительных настроек не требуется.

Файл `.nojekyll` уже добавлен: он отключает обработку файлов через Jekyll и
гарантирует, что папка `assets` отдаётся как есть.
